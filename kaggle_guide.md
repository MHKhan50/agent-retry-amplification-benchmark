# Kaggle upload guide

1. Run `python3 run_benchmark.py`.
2. Confirm `data/scenarios.csv`, `outputs/episode_results.csv`, `outputs/policy_summary.csv` and `outputs/summary.json` exist.
3. Create a Kaggle dataset named `agent-retry-amplification-benchmark`.
4. Upload the scenario CSV and output files. Include `README.md` and `dataset_card.md` in the dataset description or files.
5. State clearly that the data is synthetic and generated by a deterministic simulator; do not describe it as production telemetry.
